# Reviewer Demo Guide - 5-Minute Zero-Config Walkthrough

Welcome to the **OSS-Maintainer-AI** review page. This guide provides a zero-config walkthrough of the agent runtime, showing how events from Slack and GitHub route through the same pipeline.

---

## 1. Quick Start (Run in Under 1 Minute)

You do **not** need external API keys or a live Caspian tunnel to test the AI workflow. The system automatically runs in **Offline Demo Mode** with a deterministic LLM mock.

Execute these commands in your shell:

```bash
# 1. Install dependencies
pnpm install

# 2. Copy environment example
cp .env.example .env

# 3. Run the E2E multi-channel demo
pnpm demo
```

---

## 2. What the Demo Does

The `pnpm demo` script executes the following sequence:

1. **Local DB Migration**: Configures a local sqlite database `local_dev.db`.
2. **Bootstraps Core Gateway**: Launches the Caspian Gateway.
3. **Simulates GitHub Event**: Ingests a raw issue payload, maps conversation/actor threads, resolves identities, queries the Mock LLM, formats output, and intercepts the reply callback.
4. **Simulates Slack Event**: Ingests a raw Slack mention payload, runs it through the _exact same_ pipeline, and intercepts the Slack formatted response.
5. **Detections & Traces**: Outputs clear console metrics capturing metadata like conversation IDs, actor hashes, and execution speeds.

---

## 3. Demo Commands List

- `pnpm demo` — Runs the full sequence for both Slack and GitHub channels sequentially.
- `pnpm demo:github` — Triggers only the GitHub Issue workflow pipeline.
- `pnpm demo:slack` — Triggers only the Slack Channel Thread workflow pipeline.

## 5. Going Live (Optional)

To hook up actual live Slack or GitHub workspaces:

1. Edit `.env` and set `DEMO_MODE=false`.
2. Provide your `CASPIAN_API_KEY` (obtained from `caspian init`).
3. Set your `LLM_API_KEY` and preferred `LLM_PROVIDER` (e.g. `gemini`).
4. Set up channel tunnels:
   - GitHub: `pnpm caspian:connect-github`
   - Run the app: `pnpm dev`
